# 归档：登录口令显示按钮

<!-- archived-status-snapshot -->
> 已归档：只记录标题日期的验收与处理范围，文中的测试数量、运行中或未推送描述均为历史事实。当前有效状态统一见[CURRENT_STATUS](CURRENT_STATUS.md)。

用户反馈：手机夸克登录时，输入口令后显示密码的按键消失。检查发现原登录组件只有type=password输入框，没有网站自己的显示/隐藏按钮；浏览器原生控件的行为无法据此确定，但网站此前没有提供稳定的替代操作。

本轮在创建身份与解锁已有身份共用的口令框旁增加固定“显示/隐藏”按钮。按钮type=button，不提交登录表单，带输入框关联与可访问状态；输入和失焦不移除按钮。切换登录模式、成功导入备份或开始登录时恢复隐藏状态；登录期间禁用。口令状态及本机加密、挑战签名逻辑保持原实现。按钮至少72px宽、44px高，输入框允许收缩。

验证：格式、TypeScript检查及前端构建通过；wallet、frontend-session、auth-navigation共18项测试通过。本地实际浏览器验证输入后失焦仍可见、显示/隐藏类型切换、模式切换及登录尝试恢复隐藏。390px手机宽度检查无横向溢出，按钮高约44.7px。浏览器对口令值作脱敏，因此未把受限的value读取当作值保留断言。证据与截图在data/password-toggle-2026-10-25/，截图为本地桌面浏览器的手机宽度预览，未宣称安卓实机已确认。
