## 新增能力

| 能力 | 实现及验收范围 |
|---|---|
| 个人授权到期 | 素材阅读/编辑、声明阅读支持 expiresAt 毫秒时间戳，null 为长期；直接访问、分页、统计和导出均检查当前时间。后台清理不是权限失效的前提。不能给所有者添加到期时间；独立机构授权仍按机构规则生效。 |
| 浏览器文件核对 | 上传前计算 SHA-256，核对上传回执的大小和摘要；签署前有界下载待签素材并重新核对实际字节。EIP-712 类型由客户端构造，不直接签服务端提供的 types/message。它不等于浏览器重新执行图片编辑。 |
| 严格响应与接口说明 | 59 个操作均有领域 JSON 响应或明确二进制格式；运行时拒绝额外/错误服务端字段并返回 500，统一错误响应。OpenAPI 内部引用有完整性检查。 |
| 外置文件密钥轮换 | 可写 STORAGE_KEY_FILE provider 支持重加密、阶段日志、匹配检查、提交/回滚恢复，保留旧数据及旧密钥。未恢复日志阻止 API、链和普通维护启动。没有实现通用云 KMS/Vault provider。 |
| 图片进程隔离 | 图片检查、编辑及复现放到独立子进程；并发 2、队列 8、V8 堆 192 MB、任务预算 20 秒。超时/崩溃杀死子进程并等退出再释放额度，后续任务可继续。不是逐任务操作系统 RSS/CPU 硬配额。 |
| 本机运行告警 | 每 5 秒采样，连续 3 次异常后激活、连续 2 次正常后恢复；持久化去重、次数、历史及审核人确认。网页“运行状态”显示请求、图片队列、内存和最近告警。没有发送邮件、短信或第三方通知。 |
| 数据迁移 | SQLite v6：v5 增加个人授权期限，v6 增加运行告警。保留原 ACL 表接口；升级前先备份，旧版程序不能直接运行新版数据库。 |

## 已验证

- Windows 与 Linux 各 79 项单元/回归通过；类型检查、服务端及网页生产构建通过。最终发布脚本重新执行这些检查。
- 编译版隔离服务 9 项恢复检查通过：用户签名上链、全部服务停机、加密备份、新目录恢复、内部密钥轮换、原声明/原图片读取、分页和指标、外置文件密钥轮换后再次启动并读取同一批数据。
- 当前 Windows 服务及无 tsx 的 Linux 生产容器各完成 8 项非 demo 业务，覆盖独立持钥、图片编辑、上链、披露、授权检查、撤回和注销。
- 子进程退出及超时故障注入后下一任务可用；真实 PNG 编辑与原引擎输出逐字节一致。未注入真实 sharp 原生段错误或进行主机断电实验。
- 千节点正确性回归包含构造与验证 1000 个真实签名；一次发布检查在 30 秒处超时后，将该单项测试时限设为 60 秒并重新验收，全部节点/结果断言保留。这不是 30 秒或 60 秒的性能达标声明。
- 外置密钥测试覆盖准备阶段、数据目录替换中断、密钥/数据已发布但日志未清除、提交/回滚、活跃锁、错误密钥和外部替换拒绝。它模拟进程中断，不构成任意文件系统断电原子性保证。
- 浏览器实际核对了运行页、日期控件、合成图片上传及本地摘要核对后的签名上链。发现日期输入丢失后改为提交时读取原生控件当前值。限时授权的服务端访问、列表、导出与回收以隔离回归测试为准；修复后的浏览器授予提交因自动审批拒绝未再次执行。此前合成测试授权已分别撤销。

报告位于 data/app/results；发布只选择可分发报告，排除数据库、私钥、浏览器身份备份、Docker 冷备份及安装程序。源码目录和 docs/SOURCE_INDEX.md 可用于定位所有实际代码。
