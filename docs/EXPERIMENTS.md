# 实验复现

在npm run dev运行时执行npm run demo生成真实四节点证据，再执行npm run test:e2e及npm run bench。前者写e2e.json，后者写raw.jsonl、performance.csv、summary.json、performance.svg。数据在data/results，发布脚本选择性打包。

计时在同一进程采用performance.now，3次预热、30次重复，输出中位数及p95。分别测文件哈希、签名核验、完整证据离线核验、部分披露核验、ZIP导入/导出和最终合成复算。RPC及链确认不混入离线运算。gas数据直接来自当前链交易收据。

安全对照生成文件修改、父替换、字段修改和父缺失。B0仅检查文件，B1仅签名声明，B2使用同协议完整披露，选择性披露牺牲了部分复算可用性。没有同安全性的普遍性能领先结论。只做了4节点微基准，计划中的大规模和跨平台实验尚未完成。

消融当前仅报告取消在线链检查后的offline/incomplete，不包含完整的父槽位/操作绑定消融实现。不得把未来实验写入已完成成果。后续扩展应新增固定数据配置、保留全部失败记录、区分不支持和错误分类。
