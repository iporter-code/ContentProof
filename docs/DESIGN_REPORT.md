# 内容证链设计说明

本文维护当前架构；有效验收和未完成项统一见 [CURRENT_STATUS](CURRENT_STATUS.md)。首版31项测试和单机设计的原始快照已保存在[归档设计报告](archive/DESIGN_REPORT_2026-10-26.md)。

## 声明与证据

文件摘要、编辑操作、参数、有序父关系、私有字段承诺、签名者和链域共同绑定到声明。字段/父关系使用分域Merkle承诺；用户在浏览器核对签署意图，再生成EIP-712签名。链保存承诺、身份授权和撤回状态，私有字段及素材在链下受访问控制和加密保护。

核验器安全读取ZIP，按严格schema重算声明ID、签名和披露承诺，遍历来源图，核对文件、链状态、密钥状态及可重现编辑。隐藏来源、缺失材料、声明撤回、签名与文件匹配分别报告，不能把部分披露等同于完整验证通过。

## 身份、权限与持久化

默认用户持钥，入口先解锁身份再挑战登录；浏览器金库以PBKDF2派生的AES-GCM密钥加密，备份恢复原身份并使用原口令。浏览器来源和存储相互隔离。CSP约束可执行脚本与资源来源，但不消除XSS或已解锁密钥的风险。

服务端支持机构人工审核、邀请和角色、素材/声明授权、到期、撤销与机构暂停。SQLite记录加密私有内容与持久任务；任务按租约、回执和索引恢复处理。文件密钥、Vault KV v2及Transit信封各有明确provider，阶段日志用于恢复中断轮换。

## 执行与部署

图片任务在独立进程中执行；历史引擎通过专用账号、网络和文件系统隔离。API和本地参考链由supervisor管理，退出时等待拥有的子进程；Nginx提供HTTPS和共享安全头。备份在停机一致性边界生成，加密保存并保留回滚材料。

单机持久参考链与可部署的Besu QBFT网络分开记录；同机共识/故障检查不代表完成跨机构、恶意节点或生产高可用验收。异机恢复和生产KMS/Vault仍需独立资源。

## 协议边界

自定义sidecar证据协议与原生C2PA内嵌离线核验分别实现。原生核验器按配置pin、来源和二进制摘要验证运行能力，报告显示同一配置版本；不自动信任随文件附带的证书，不进行在线撤销或远程manifest抓取。

签名证明声明者和绑定关系，不证明内容事实、版权、机构资质或模型提供方认证。完整音视频编辑链、零知识证明、水印与外部可信时间戳仍是扩展范围。
