# 内容证链设计报告（代码配套初稿）

## 问题与方案

多机构流转图片时，平台数据库的一句“验证通过”不足以作为证据。系统把原文件、操作、输入顺序、私有字段承诺、签名者及链域绑定到一份声明中，通过ZIP交付可独立检查的材料。

核心实现是字段/父关系分域Merkle树、EIP712声明、密钥与内容登记两合约、受控图片编辑复算、披露感知的七项报告。链只保存可验证承诺和状态，私有字段与原图链下保存；ACL控制访问，AES-GCM保护持久化私有内容。

编辑/签名流程：上传检查→建立草稿→准备core→用户/演示测试账户签名→API核验签名→持久化任务→合约检查→回执→事件索引。交易超时先查claimId；恢复不更改已签署内容。

验证流程：安全读取ZIP→严格JSON/schema→重算claimId和签名→验证披露承诺→遍历父图→检查文件→在线读取链和密钥状态→在输入/参数/引擎齐备时复算→输出逐项理由。CLI没有业务API或数据库依赖。

## 功能指标

PNG/JPEG输入；每文件20MB/2000万像素；PNG确定编码输出；裁剪、缩放、90度旋转、两图合成；128字段及8父槽位协议上限；64图深及1000节点遍历上限；128MB ZIP上限；本机chainId31337。上限是校验约束，不代表已经完成满载性能实测。

## 原创性与已有工作

内容来源、签名、Actions、Ingredients和Redaction已被C2PA定义。本实现不宣称首创这些概念，也不宣称兼容C2PA。候选贡献是披露覆盖的明确语义、操作上下文绑定和业务服务之外的独立检查；是否有研究创新需进一步比较论文和开源方案。

## 当前验证

31项单元测试、28项实际本机端到端检查和30轮小样本性能微基准均有对应脚本。真实合成版本可被CLI复算，隐藏父素材后输出incomplete/withheld/unavailable。详细结果见TEST_REPORT.md及data/results，不把功能测试等同形式化安全证明。
