# 能力限制

系统证明签署声明及其已提供证据的一致性，不证明画面事实、版权、真实拍摄或AI提供方身份。平台外加工后重新导入的文件，没有办法仅靠哈希找回所有未声明素材。AI字段是签署者声明，未对接模型方回执。

选择性披露隐藏原文和盐，不隐藏签名者、根、数量、文件大小、操作类型及一切图像侧信息。隐藏素材可能通过其他公开路径出现；派生图片本身也可能暴露源图内容。缺少来源是未知或不完整，不等于内容虚假。

默认是持久化单机参考链及用户自持密钥签名。已有同机Besu QBFT、容器和限定图片/协议规模验收，不代表多机构独立部署、生产高可用、任意文件编码确定性或持续容量上限。当前C2PA入口仅覆盖原生内嵌离线核验。更多实际范围见IMPLEMENTATION_STATUS.md。

浏览器签署会根据本地保存的原始字段、参数和有序父输入重新计算承诺，并固定已确认的链和合约；这要求浏览器及前端代码可信。如果攻击者能够替换交付给用户的前端代码，本地检查本身也可能被替换。派生图片是否由约定引擎按参数产生，仍由独立复算确认。
