# 演示脚本

1. npm run dev保持服务；另开终端npm run demo生成真实素材、四声明和两个证据包。
2. 页面选择发布机构C。声明记录选择最新合成，查看链上区块、签名者、父根和字段根。
3. 来源图解释A导入→B裁剪→C合成，同时另一素材进入合成。箭头顺序受签名绑定。
4. 披露设置隐藏ai.prompt、source.location及一个父素材，解释仍暴露结构数量和签名地址。
5. 验证中心分别上传full.zip与private.zip。前者pass且reproduced；后者incomplete，区分合法隐藏与篡改。
6. 终端运行独立CLI同一证据包，表明不调用业务API；加--offline明确未检查最新撤销状态。
7. npm run test:e2e展示实际攻击实验；打开原始e2e.json而非只展示终端绿色文本。
8. 介绍微基准的样本、重复和局限。主动说明来源不等于事实/版权，AI属性为签名者声明。

准备时固定Node及依赖、保持内存链运行；不要现场重启链导致历史登记消失。不得使用虚假合作机构或将研究候选贡献称为已证明的首次创新。
