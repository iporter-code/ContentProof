# 手机签署与最近声明检查

用户实机：安卓、夸克、https://47.108.145.159。已确认图片上传成功；点击“执行、签名并上链”时没有确认框，直接出现“已取消，草稿保留以便恢复”。

## 原因与处理

旧版用浏览器原生 confirm，取消返回会终止签署。实机未展示该窗口，符合浏览器抑制原生对话框的现象，尚未取得该手机的浏览器内部日志，不能断言具体抑制机制。

签署、登记网络核对、备份下载选择、密钥操作及撤回均改为页面内确认窗口。只有点击“确认并继续”才继续；取消、Escape、页面离开、身份锁定或会话失效会取消。并行请求不能替换正在核对的内容，旧窗口的确认不能批准另一请求。保留文件摘要和本地签署意图核对。

最近声明列表增加加载状态、加载失败说明、刷新按钮，以及“草稿不会出现在已签署声明列表”的空状态提示。没有修改声明读取权限，也没有把草稿伪装成已签署记录。

线上匿名只读统计：最新创建的身份有 5 份草稿、0 条已签署声明，与用户此次签署被取消的情况一致；这不能单独证明该身份就是当前手机身份。签署完成后才会形成正式声明。
